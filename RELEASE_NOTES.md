# Release Resim Dönüştürücü v1.0.0

-Initial release of Resim Dönüştürücü (Image Converter)
-Convert HEIC/HEIF images to JPEG, PNG, WebP or BMP (and convert JPEG/PNG/WebP/BMP between each other)
-Source and target format selection, files in the wrong format are rejected with a clear message
-Maximum quality output, no quality settings
-Unlimited number of files, drag and drop anywhere on the page, folders supported
-Download each file separately or use Download All (no ZIP)
-Turkish (default) and English interface, dark and light theme
-Everything runs locally in your browser, no files are uploaded
-Custom application icon, Turkish file name and version info
-Added GitHub button and Clear List button
-The app closes itself when you close the browser tab

## Notes

-JPEG and WebP are lossy formats, PNG and BMP are lossless. EXIF metadata is not preserved. HEIC output is not supported.
-Windows may show a SmartScreen/antivirus warning because the executable is not code-signed (More info > Run anyway). You can verify the download with the hashes below or build it from the source code.
